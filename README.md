# Java Day 51 – Hotel Room Booking Management

## Description
A Java application for managing hotel room reservations, customer bookings, room availability, and booking cancellation.

## Features
- Display room availability.
- Book hotel rooms.
- Generate booking IDs.
- Calculate booking bills.
- Search bookings.
- Cancel reservations.
- Store booking records in a text file.

## Files
- `Main.java` – Main Java application.
- `bookings.txt` – Sample booking database.

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- ArrayList
- File Handling
- Lambda Expressions
- Searching and Removing Records
- Exception Handling

## Note
This project uses a fixed room capacity and a fixed educational room rate of ₹1,500 per day.
